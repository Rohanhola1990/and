# Amar Nath Das — Portfolio

Next.js 14 portfolio. Dark olive theme, teal accents, editorial typography.

## Local Dev
```bash
npm install
npm run dev
# open http://localhost:3000
```

## Before deploying
- Replace `public/cv.pdf` with your actual CV file
- Update LinkedIn / GitHub URLs in `components/Fun.js` and `components/Footer.js`
- Update buymeacoffee URL in `components/Fun.js`

## Deploy to Vercel
1. Push this repo to GitHub
2. Go to vercel.com → New Project → Import from GitHub
3. Select this repo → Deploy (zero config needed)
